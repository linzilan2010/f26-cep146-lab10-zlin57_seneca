# CEP146 Lab 10 - Software Licensing

## Introduction
This lab focuses on understanding software licenses used in GitHub projects and creating a custom license for an AI model.

## Exercise 1: License Detective (Solo)
Research five machine learning projects on GitHub and compare their software licenses.

Topics covered:
- License types (MIT, Apache 2.0, BSD, GPL)
- Commercial use
- Attribution requirements
- Modification and redistribution
- Special restrictions

## Exercise 2: Build Your Own License (Group of 2)
Create a custom software license for an AI model that recognizes emotions in text.

The license covers:
- Who can use the model
- Modification, redistribution, and commercial use
- Attribution and sharing requirements
- Prohibited activities
- Consequences of license violations
