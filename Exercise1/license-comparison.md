# Exercise 1: License Detective

## Objective
Research five machine learning projects on GitHub and compare their software licenses, including commercial use, attribution, modification, redistribution, and special restrictions.

## License Comparison Table

| Project | License Type | Commercial Use | Attribution Required | Modify and Redistribute | Special Requirements |
|---|---|---|---|---|---|
| [micrograd](https://github.com/karpathy/micrograd) | MIT | Yes | Yes | Yes | Keep the original copyright and license notices. |
| [TensorFlow](https://github.com/tensorflow/tensorflow) | Apache 2.0 | Yes | Yes | Yes | Keep license and required notices, state modifications, and follow patent-related terms. |
| [scikit-learn](https://github.com/scikit-learn/scikit-learn) | BSD 3-Clause | Yes | Yes | Yes | Keep copyright notices and do not use contributors' names for endorsement without permission. |
| [MatPL](https://github.com/LonxunQuantum/MatPL) | GPL 3.0 | Yes | Yes | Yes | Distributed derivative software must follow GPL requirements and provide corresponding source code. |
| [Ultralytics YOLO](https://github.com/ultralytics/ultralytics) | AGPL 3.0 | Yes, with conditions | Yes | Yes | Copyleft requirements apply, including source code availability for certain network-based uses. |

## Analysis

### 1. MIT License
MIT is a permissive license. It allows commercial use, modification, and redistribution. Users must keep the original copyright and license notices.

### 2. Apache License 2.0
Apache 2.0 allows commercial use and modification. Users must retain required notices and identify changes. It also includes an express patent license.

### 3. BSD 3-Clause License
BSD 3-Clause allows commercial use, modification, and redistribution. Users must keep required notices and cannot use the original creators' names to promote modified products without permission.

### 4. GPL 3.0 License
GPL 3.0 allows commercial use, modification, and redistribution. When distributing covered derivative software, users must follow GPL requirements, including making corresponding source code available.

### 5. AGPL 3.0 License
AGPL 3.0 is similar to GPL 3.0 but also includes source-sharing obligations for certain modified software accessed by users over a network.

## Conclusion
MIT, Apache 2.0, and BSD 3-Clause are permissive licenses that allow flexible reuse. GPL 3.0 and AGPL 3.0 use copyleft rules to help keep covered derivative software open source. The best license depends on how creators want others to use and share their software.
